# EquiAI Research Project Website

**A beautiful, single-file website for the EquiAI AI research project — using advanced machine learning to price and predict assets more accurately and reduce economic inequality.**

## ✨ Overview

This is the official landing page and demo site for **EquiAI**, an academic research initiative that combines cutting-edge AI (Transformers + Graph Neural Networks) with fairness constraints to create more accurate and equitable asset pricing models.

The entire website is contained in **one single HTML file** — no build step, no framework dependencies beyond Tailwind CDN and Chart.js. Perfect for rapid deployment on GitHub Pages, Vercel, Netlify, or any static host.

## 🎯 Project Mission

EquiAI aims to:
- Eliminate information asymmetry in financial markets
- Democratize high-quality asset pricing signals
- Reduce global wealth inequality through better predictions
- Make state-of-the-art financial AI open, reproducible, and fairness-first

## 📋 Features

- **Fully responsive** modern design with Tailwind CSS
- **Interactive AI price prediction demo** (runs 100% in-browser using a distilled model simulation)
- **Animated hero chart** showcasing EquiAI vs traditional models
- **Live sliders** for volatility and sentiment that update in real time
- **Impact metrics**, team profiles, publications, and research methodology
- **Dark mode** by design (research aesthetic)
- **Mobile-friendly** navigation with smooth scroll
- **Zero JavaScript build** — just open and go

## 📥 Installation & Deployment

### Option 1: Quick Start (Recommended)
1. Download or copy the entire `index.html` file from this repo
2. Save it as `index.html`
3. Open it in your browser → done! 🎉

### Option 2: Deploy in < 60 seconds
```bash

cd equiai-website
# (replace index.html if you customized it)
